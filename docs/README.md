# SaaS Multi School Management System

## Overview

Aplikasi SaaS untuk manajemen sekolah multi-tenant.

Setiap sekolah memiliki data sendiri seperti:
- siswa
- guru
- kelas
- jadwal
- nilai
- absensi

---

## Roles

- Super Admin
- School Admin
- Teacher
- Student
- Student Parent

---

## Main Features

### Super Admin
- CRUD School Profiles
- CRUD Users
- CRUD Roles

### School Admin
- Manage Students
- Manage Teachers
- Academic Year
- Semester
- Subject
- Classroom
- Schedule

### Teacher
- View Own Schedule
- Input Attendance
- Input Scores
